## Release copy

HarmonyScreen by YouWo.ai turns a compatible Huawei HarmonyOS device into an
extra Mac display over USB. The free developer preview supports full-screen
video, portrait and landscape, automatic sizing and live stream FPS.

Verified on Mate XT 2. The Mac preview is available on GitHub; native Huawei
installation currently requires developer signing. General installation and
Mac notarization are still in progress. Based on SideScreen, under MIT.

Download and setup: https://github.com/Shonn-Li/HarmonyScreen
YouWo: https://youwo.ai
